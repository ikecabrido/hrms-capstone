Chart.js Local Copy
===================

Download the following file and place it in this directory:

File: chart.umd.min.js
Source: https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js

Steps:
1. Open the URL above in a browser when internet is available
2. Save the page as chart.umd.min.js in this directory
3. Refresh the dashboard page

The dashboard will continue to work without Chart.js; charts will simply not render.
